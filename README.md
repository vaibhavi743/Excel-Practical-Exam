# 📊 Data Intelligence Dashboard

### Customer Sales Analysis

## 📌 Project Overview

The **Data Intelligence Dashboard** is a data analytics project developed using Microsoft Excel to analyze customer sales performance and transform raw data into meaningful business insights.

This project uses data cleaning techniques, Excel formulas, PivotTables, and visualizations to create an interactive dashboard that helps users understand sales trends, profitability, regional performance, and product category contributions.

## 🎯 Project Objectives

* Analyze customer sales and profit data.
* Identify top-performing regions and product categories.
* Evaluate sales and quantity performance.
* Highlight the top 10 sales values.
* Create an interactive and visually appealing dashboard.
* Present data-driven insights to support business decisions.

## 📂 Dataset Description

The dataset contains customer transaction and sales information with the following fields:

| Column           | Description                |
| ---------------- | -------------------------- |
| Customer_ID      | Unique customer identifier |
| Customer_Name    | Customer name              |
| Region           | Customer's sales region    |
| Product_Category | Product category           |
| Sales            | Sales amount               |
| Quantity         | Units purchased            |
| Discount         | Discount applied           |
| Order_Date       | Date of order              |
| Profit           | Profit earned              |

## 🧹 Data Cleaning & Preparation

The dataset was prepared for analysis by:

* Checking for missing and duplicate records.
* Reviewing column names and data consistency.
* Verifying numerical and date formats.
* Ensuring sales, quantity, discount, and profit fields were suitable for analysis.
* Organizing the dataset for PivotTable and dashboard creation.

## 🧮 Excel Functions Used

| Function    | Purpose                              |
| ----------- | ------------------------------------ |
| `SUM()`     | Calculate total sales and profit     |
| `COUNTA()`  | Count records                        |
| `IF()`      | Apply logical conditions             |
| `VLOOKUP()` | Retrieve matching information        |
| `INDEX()`   | Return a value from a selected range |
| `MATCH()`   | Find the position of a value         |
| `LARGE()`   | Identify top sales values            |
| `SUMIFS()`  | Calculate totals based on criteria   |

## 📊 PivotTable Analysis

## 📈 Dashboard Visualizations

The project includes visualizations such as:

* **Bar Chart:** Compare sales across regions or categories.

* **Line Chart:** Present trends over time.
* **Top 10 Sales Chart:** Highlight the highest sales values.
